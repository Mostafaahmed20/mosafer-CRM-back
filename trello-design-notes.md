# Trello Design System Analysis

## Color Palette
- **Primary Blue**: #0079BF (Trello brand blue)
- **Background**: White/Light gray (#FAFBFC)
- **Card Background**: White (#FFFFFF)
- **List Background**: #EBECF0 (light gray)
- **Text Primary**: #172B4D (dark blue-gray)
- **Text Secondary**: #5E6C84

## Label Colors (Standard Trello)
- Green: #61BD4F
- Yellow: #F2D600
- Orange: #FF9F1A
- Red: #EB5A46
- Purple: #C377E0
- Blue: #0079BF
- Sky: #00C2E0
- Lime: #51E898
- Pink: #FF78CB
- Black: #344563

## Card Features
1. **Labels** - Color bars at top of card
2. **Due dates** - With status indicators (overdue=red, due soon=yellow, complete=green)
3. **Checklists** - Progress bar showing completion %
4. **Attachments** - File icons and count
5. **Comments** - Comment icon with count
6. **Members** - Avatar circles
7. **Cover images** - Full-width image at top of card
8. **Description** - Text indicator icon

## Typography
- Font: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto
- Card title: 14px, medium weight
- List title: 14px, semi-bold
- Board title: 18px, bold

## UI Components
- Rounded corners: 3px (cards), 8px (buttons)
- Shadows: subtle box-shadow on cards
- Hover states: slight background color change
- Transitions: smooth 0.2s transitions

## Key Features to Implement
1. Card labels with colors
2. Due dates with visual status
3. Checklists with progress
4. Card cover images
5. Member avatars on cards
6. Comments section
7. Archive functionality
8. Search and filter
